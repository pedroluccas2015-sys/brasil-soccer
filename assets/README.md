# Assets originais

Os sprites são desenhados em pequenos canvases e armazenados em cache por uniforme, animação, direção e frame, em `js/renderer.js`. O campo, redes, arquibancada, torcida, árbitro, bandeirinhas e interface também são procedurais. O SVG da bola foi criado para este projeto.

Os diretórios players, kits, stadiums e audio são pontos de extensão para futuros spritesheets e sons. Nenhum arquivo externo é necessário: sons e sequência musical original são sintetizados em `js/audio.js` pela Web Audio API.

Não há imagens, escudos oficiais, músicas, fontes ou sprites extraídos de outros jogos. Os emblemas da seleção são formas geométricas com siglas.
